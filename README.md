# yokai-watch-index

妖怪ウォッチ アニメ・妖怪検索（**非公式ファンサイト**）

妖怪ウォッチの「妖怪図鑑」と「アニメエピソード」を相互参照できる検索サイトです。
家族で使うために作った非営利の個人プロジェクトで、公式とは一切関係ありません。

## できること

- 妖怪を種族・ランク・属性・色・好物などで絞り込んで探す
- アニメの各話を、登場する妖怪や人物から探す
- 「この妖怪はどの回に出た？」「この回には誰が出る？」を相互に辿る
- 見つけた話を公式YouTube「妖Tube」で再生する（外部リンク）
- 見た話・持っているメダルを記録する（ブラウザ内のみ）

対象は **初代『妖怪ウォッチ』（EP001-214）** と **『妖怪ウォッチ♪』（MN001-096）** です。

## 扱わないもの

- **画像**（取得・保存・表示のいずれも行いません）
- 取得元の原文（あらすじ・解説などの散文）
- ゲームの攻略情報・ステータス数値
- 広告・アフィリエイト

理由は [SPEC.md §2](SPEC.md) に記載しています。

## 開発

```
CLAUDE.md          作業の入口
SPEC.md            仕様の本体（版 2.1）
DECISIONS.md       仕様に書かれていない判断の記録
STATE.md           進捗。中断した場合はここから再開する
files/             着手前レビューの記録
```

### 構成

```
raw/        取得元の原文（gitignore）。人間が Special:Export で配置する
overrides/  人間が手で書く対応表。パイプラインの入力
scripts/    本番パイプライン
reports/    検証出力（gitignore）
docs/       GitHub Pages の公開ルート。サイト一式と data/*.json
```

データフローは **`raw/` → `scripts/` → `docs/data/` → `docs/` の一方向**です。

### 実行

```bash
python3 scripts/parse_fandom.py
```

依存は標準ライブラリのみです（`requirements.txt` を参照）。
YouTube API を使うスクリプトは `.env` の `YT_API_KEY` を読みます（`.env.example` を参照）。

## 検索エンジンについて

第一弾は `noindex` と `robots.txt` の `Disallow: /` を設定しています。
データの誤りや突合の失敗を家族で使いながら潰してから公開する方針です。
