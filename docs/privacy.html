記録するもの

「見た話」と「持っているメダル」の記録は、 お使いの端末のブラウザの中（localStorage）にのみ保存されます。 サーバーには送信していません。送信する仕組み自体がありません。

本サイトは GitHub Pages で配信される静的なページで、 利用者のデータを受け取るサーバーを持っていません。

記録を消したいときは、「きろく」タブの「ぜんぶ消す」を押すか、 ブラウザの設定でサイトデータを削除してください。

アクセス解析

アクセス解析ツールは入れていません。Cookie も使っていません。

ホスティング元である GitHub が、配信にともなう標準的なアクセスログ （IPアドレス等）を取得している場合があります。これは本サイトの管理者が 設定したものではなく、閲覧することもできません。詳細は GitHub のプライバシーに関する声明 をご確認ください。

外部へのリンク

各話の「▶ 見る」は YouTube へのリンクです。動画は本サイトに埋め込んでおらず、 リンクをタップして YouTube を開いた時点で、 Google のプライバシーポリシー が適用されます。リンクを開かないかぎり、YouTube との通信は発生しません。

出典元である Fandom へのリンクも同様に、リンク先の方針が適用されます。

広告

広告・アフィリエイトは設置していません。収益化を一切行っていません。

画像

本サイトは画像を一切扱いません。妖怪のイラスト、アニメの場面、メダルの画像などを 取得・保存・表示することはありません。種族や属性は色と図形で表しています。

お問い合わせ

ご指摘・削除のご依頼は GitHub Issues までお願いします。
