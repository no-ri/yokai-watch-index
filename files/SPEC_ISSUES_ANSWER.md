### A-2. 劇場版 → **推奨案3を採用**

### A-3. A1 ゲートの分母 → **「動画が対応するセグメント」**

`yotube_video_id` が非 null のセグメントを分母とします。全1,186セグメントではありません。

理由: A1 が問うているのは「妖Tube の説明欄から日本語要約を生成できるか」であって、
「全セグメントに動画があるか」ではありません。動画がないセグメントは A1 の失敗ではなく対象外です。
動画の有無は `data_status` で別に追跡しており、分母に含めると同じことを二重に測ることになります。

**あわせて `is_recurring` フラグを追加しました（§5.14）。**

♪が1話あたり5.89セグメントになる原因は、MN001 の内訳が示すとおり
「手を洗おう」「4コマ」「妖怪劇場」のような定期ミニコーナーが含まれるためです。
これらは対等なセグメントではなく、妖Tube でも配信されません。

コーナーはタイトルが毎回同じ、本編は毎回違うので、
**同一 `title_ja_norm` が5話以上に登場するものをコーナーと判定**できます。
これがないと♪の画面が「動画なし」だらけになります。

閾値5話が妥当かは実測で調整してください（§17 U-8）。

**先行実測の提案は不要です。** PR4 の通常の流れで測ってください。

### A-4. Phase 3 → **第一弾に含めない**

推奨案1を採用します。判断とその理由（§11.1 との整合、INSTRUCTION.md との整合、
nullable なのでスキーマが壊れない）はいずれも正しいです。

SPEC §14 に「第一弾のスコープは Phase 2 → Phase 2.5 → Phase 4」と明記しました。
`intro_ja` / `etymology_ja` / `synopsis_ja` / `keywords` はすべて null で構いません。

**「勝手に決めずに確認した」判断は適切でした。** §11 の設計判断に関わる箇所です。

### B-6. ja.Wikipedia → **PR3 をスキップ**

`japan` パラメータが 310/310 で存在するという実測は、
私の「ここからしか取れない」という記述を覆します。**私の誤りです。**

第一弾では ja.Wikipedia を使いません。

```
air_date       Fandom の {{episode}} の japan（"January 8, 2014" 形式をパース）
staff          同 screenplay / storyboard / director / amindirector / animation

```

`title_ja_full` は §9.2 の検索軸に含まれず、そもそも妖怪ウォッチのエピソードに
「総題」という概念が存在するかも未確認です。未検証の外部依存を1つ減らします。

**PR3 は欠番としてください。** PR 番号は振り直さず、PR2 の次は PR4 で構いません。
